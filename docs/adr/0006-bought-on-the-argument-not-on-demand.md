# ADR 0006: The breaker is bought on the argument rather than on demand

**Status:** accepted, 25 August 2026.

## The admission

**Drawdown, kill switch, circuit breaker and position limit each reach zero employers** in the
posting register behind this portfolio. Not few. Zero.

Every other component here was chosen because the capability was seen being asked for. This one
was not, and the README says so in its limitations rather than implying a demand that was never
measured.

## Why it is here anyway

Because a breaker without an obligation is a print statement, and the repository's argument is
incomplete without showing that.

The absorbing UNKNOWN is a claim about an outcome nobody can confirm. Order state is the obvious
place to make it and the easy place to dismiss it, because a reader can tell themselves a real
venue would eventually answer. The obligation makes the same argument in a second place where
there is no venue to blame: the deadline passed, the position was open, and nothing outside this
system had anything to do with it.

One instance of an idea is an anecdote. Two instances in different parts of one system, reaching
the same terminal answer for the same reason, is a design.

## The honest cost

A reviewer who scores this repository by counting the technologies it demonstrates will not count
the breaker, and they will be right not to. It is here for the integrity of the argument, and
that is the whole justification.
